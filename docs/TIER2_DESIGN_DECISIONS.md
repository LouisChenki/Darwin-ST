# Tier-2 创造层设计决策 (LLM/Agent 强化 AutoML)

> 2026-06-18 · 用户与 Claude 深度讨论结论。在 P3 之前确立, 指导 P3 + Tier-2 实现。
> 前置: docs/P2_ALGORITHM_DESIGN.md(P2 确定性引擎已完成并点火). 本文档是 P2→国际领先的关键跃迁。

## 0. 问题与赌注

文献事实: 现有 AutoML/NAS(AutoCTS/AutoSTF ~18.4) **追不上**手工 SOTA(STAEformer 18.22 / STD-MAE 17.80)。
根因 = NAS 的四个结构缺陷: ①搜索空间天花板(只能重组固定算子, 不能发明新机制) ②无因果理解(架构是不透明基因) ③无跨域迁移(困在自己搜索空间) ④局部搜索(大突破是非局部跳跃)。
**这四点恰是 LLM 的强项。** 引入 LLM/agent 不是锦上添花, 是直击 AutoML 命门。这是论文核心创新, 也是研究赌注(能逼近/匹配 SOTA, 不保证严格超越)。

## 1. 五大能力 C1-C5 (不分主次, 互相喂养)

```
C3 跨域知识(燃料) ──供给──▶ C1 算子合成(引擎) / C5 训练范式进化(引擎)
C2 因果诊断 ──引导──▶ 决定 C1/C5 往哪发明
C4 锦标赛预筛 ──过滤──▶ 决定哪些发明值得烧 GPU
```
- **C1 搜索空间扩张**: LLM 写新算子代码(新 nn.Module), 注入算子库 → 搜索空间自己生长。对照: 固定算子集(=传统 NAS)。
- **C2 因果诊断变异**: LLM 读训练曲线+memory 诊断 why(过平滑/梯度爆炸...) → 定向修。对照: 盲变异。
- **C3 跨域知识涌现**【上限决定者】: KG 检索其它领域机制(CV 掩码自编码、SSM/Mamba) → LLM 类比嫁接。时空近年真突破(STD-MAE)都是跨域移植非本域重组。对照: 无 KG。
- **C4 idea 锦标赛预筛**: LLM panel 辩论排名, 只烧 top-K。20min/trial 算力约束下直接提样本效率。对照: 不预筛。
- **C5 训练范式协同进化**: LLM 进化预训练/数据增强/损失/课程(不只架构)。STD-MAE 优势来自掩码预训练=训练范式创新, 纯架构 NAS 搜不到。这也回应用户最初需求第6点(训练过程优化), 是"为何非 LLM 不可"的硬论证。

每个 Ci 设计成**可独立消融的贡献点**, 即使没严格超 SOTA 论文仍成立。

## 2. 系统形态: C-hybrid (已拍板)

**Darwin-ST = 自包含 Python 研究系统(确定性骨架) + Tier-2 低频外包给 coding LLM 发明新机制。**
SKILL.md 退化为"启动器 + 给宿主 agent 的说明书"; 真正的多角色协同在 Python 编排器里被精确控制(自主性铁律: 结构放代码, 别靠 LLM 自觉)。

- **Tier-1 (确定性 Python, 7×24 高频)**: 进化+HPO+调度+archive+memory+程序化停止。**不写代码、不调 LLM**, 已完成并点火。架构重组(换/接/调算子)是纯结构化 genotype 变异, 不需 LLM。
- **Tier-2 (LLM, 低频, 停滞时触发)**: 发明新算子(C1)/训练范式(C5)/跨域嫁接(C3)/因果诊断(C2), 经锦标赛(C4)筛选。
- **算力线路 = API (已拍板)**: 编排器直接调 LLM API, 自包含、真无人值守打榜。用户接入自己的 key。

### 2.1 写代码外包给 Aider (已拍板, 参考 AI Scientist)
AI Scientist 用 Aider 做代码生成("template-based system uses Aider")。Aider = 命令行 AI 结对编程, **用受约束 SEARCH/REPLACE diff 直接编辑文件 + 自动落盘 + 跑测试 + 读报错自我 debug**, 解决了"如何从 LLM 回复精准抽取有效代码"——**不靠抽取, 靠约束生成+验证**。
- 编排器在 Tier-2 触发点给 Aider: 结构化指令 + 验证标准(算子签名 forward(x,adj)→[B,T,N,F]、过 pytest)。
- Aider 写+自我 debug 到通过我们的测试。
- 我们的 **P0 评测地基 + builder 形状/可微测试 = 最终验收(防 reward hacking)**。FunSearch 能让 LLM 自由生成不崩, 正因评测器绝不放过没真跑通的。
- **沙箱隔离**(关键风险): Aider 改真实代码库, 必须在 git worktree/副本里改, 测试通过才合并, 防坏算子污染。

## 3. 多智能体 = 轻量面板 (承载 C1-C5 的组织骨架)

面板是"结构"(能力怎么被组织), C1-C5 是"能力"(系统能做什么)。映射:
| 面板角色 | 承载 | 说明 |
|---|---|---|
| Generator 生成者 | C1+C2+C3+C5 | 合成算子/诊断驱动/跨域嫁接/训练范式, 候选都在这产出 |
| Ranker 排名者(锦标赛) | = C4 | Elo/辩论排名, 只送 top-K 烧 GPU |
| Critic 批判者 | 质量门(非某个C) | **重定向为 ST 调优批判**(见下), 非照搬 AI-Scientist |
| Meta-review 元综述 | ExpeL 升级 | 跨轮经验蒸馏→回灌生成者(reflect.py 升级) |

**多智能体真伪关键**: 必须独立上下文+不同角色+(批判者)对抗目标, 否则单上下文轮流扮演=模式坍缩(自说自话)。协调结构编码在 orchestrator, 不交给 skill-agent 临场拼。

### 3.1 Critic 重定向 (用户洞察)
内层目标是**打榜降 MAE 非产出新颖论文**, 故批判者**不查文献新颖性**, 改查: 失败预测(NaN/过平滑/OOM/过拟合, 基于 graveyard+architecture-rules)、形状/可微 sanity(保节点维N)、资源可行性(20min/显存)、效果合理性(对症当前瓶颈)、冗余查重(对照**自己历史**非世界文献)。文献级新颖性留到更高层(判断整套方法值不值得写论文), 不进内层循环。

## 4. 知识本体: 以机制为中心 (P3 重定位)

P3 的 KG 目标从"ST-GNN 技巧库"**扩为"跨域机制库"**(才有跨域素材)。语料范围扩到含序列建模/图学习/自监督/CV 等邻域。
本体**以 Mechanism 为中心**(非数据集/症状), 关键是在"抽象功能+前提条件"层对齐才能驱动类比:
```
Mechanism(如"掩码自编码")
  ├─ abstract_function: 自监督表示学习/缺失鲁棒
  ├─ preconditions: 标签稀缺/需鲁棒特征/数据有冗余结构  ← 类比钩子
  ├─ origin_domain: CV (非 ST)                          ← 跨域迁移钩子
  ├─ math_structure / evidence{dataset,Δ,grade} / anti_patterns
```
LLM 类比推理: "掩码自编码在 CV 因'数据有冗余结构'work" + "时空也有强冗余(时间周期+空间平滑)" → 前提匹配 → 值得移植。
**本体设计有研究开放性**(SciKG 未完全解决), 需调研(结构映射理论/SciKG/ORKG/机制级表示)。先给机制中心 v1, 用"能否让 LLM 成功提出一次跨域移植"检验。

## 5. 开放打榜 vs 受控创新 (已拍板)

**去掉强制创新点保护, 默认开放打榜**(知识涌现本身即创新, 不预先锁死)。保护降级为**可选 config flag**(服务"打磨用户指定创新点 X 到 SOTA"的受控叙事)。**程序启动时给用户选择界面**(配置单):
- 模式1(默认) 开放打榜: 只给数据集+目标, 自由探索冲 SOTA。
- 模式2 受控创新: 用户指定创新点(如液态神经网络), 系统围绕它打磨。
注: "保护当前冠军不被坏变异毁掉"由 archive 精英保留+aging 已实现, 不需算子锁死。

## 6. 风险

①研究赌注(可能逼近不到 0 gap)→ 叙事容纳"逼近/匹配"非只赌"超越"。②reward hacking(LLM 算子作弊压 MAE)→ 确定性评测+masked+严格协议(P0)是防线。③成本(LLM+GPU 双开销)→ 锦标赛预筛+predictor 控成本。④可复现(LLM 随机)→ 固定 seed+记录 prompt/响应+结构化输出。⑤Aider 污染代码库 → git worktree 沙箱+测试通过才合并。
