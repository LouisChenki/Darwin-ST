## 3. 关键实证发现（论文级素材）

1. **Tier-1 地板大幅抬升**：纯进化段（Stage1/2 搜索空间 + 631 卡时代变异池 + 充分训练）达 18.95，比历史"纯 NAS 天花板 20.67"高 1.7——搜索空间升级（joint/cross/iterative + Stage2 新算子）的独立贡献实证。
2. **合成算子×进化组装是突破引擎**：破 18.949 平台的领头架构（18.690）含创造 #1 的 `InfoBootstrapResidual`；第二名同含精炼产物 v2+v3。**算子的价值不在单挑成绩，而在进入基因池后的组合潜力**——v2/v3 单挑输父代，组合后远超父代。
3. **版本链（best-shot）机制成立**：`StGraphAttnWithMpsGated` 族 v1→v26 共 6 次升级（18.984→18.938→18.781→18.727→18.669→18.564，累计 -0.42），14 次精炼 6 胜——FunSearch 式"带分数代码版本链持续回炉"在真实 NAS 场景首次完整实证。
4. **诊断多样化根治**：创造 #1 命中 minimal_predictive_sufficiency（非 dilated_causal），彻底摆脱历史"6 次创造同一机制"的坍缩。

## 5. 收关判断与下一步（B7 启动方案）

**收关理由**：best 18.356 平台约 55 轮；版本链升级放缓（v26 后 0/6）；头部集群 18.356-18.42 极致致密——当前配置（线性 block 空间 + 现算子池 + 仅架构算子创造）的硬局部最优已到。

**资产清单**（全部保留）：689 试验 db、12+ 合成算子（1 族 36 版本 + 创造 #1 三算子）、家谱、履历、checkpoint top-20、631 卡库。

**B7（训练方式创造通道）启动方案**：
- 目标：让 Tier-2 不止造架构零件（nn.Module），还能造**训练辅助任务**（如对隐藏表征做时空解耦掩码重建的正则项）——STD-MAE 路线是文献中唯一被证明能把 18.5 级预测器推到 17.8 的机制（预训练贡献 0.7-1.0 MAE，与当前 gap +0.56 量级吻合）。
- 改动面：`train.py` 加辅助损失接口（模型可暴露 aux loss，按 λ 加入总损失）→ `contracts.py` 加 AUX_TASK 计划类型 → `validation.py` 加"不得偷看标签/未来"泄漏门 → 检索侧 masked_autoencoding + decoupled_st_masked_pretraining 卡已就位（B6）。
- 部署：带缺陷 1/2 修复（5aed406）的新跑，8 卡机可在此阶段启用（评估更贵）。
- Go 标准：辅助任务算子合成-验证-训练闭环冒烟通过 + 服务器长跑 best 破 18.22（STAEformer 可发表档）。
